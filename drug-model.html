Traceable

Every number has one owner and a locator that opens: a filing, a label section, a registry record, a worksheet cell. A number without one does not pass.

Graded

Every input declares its evidence tier and its basis. Observed, derived, judged or unknown — the reader always knows which, and why.

Reviewed

Nothing ships before a machine check and an independent re-read of the sources. A disagreement is disclosed on the first page, not absorbed into the number.

    Evidence

    Evidence arrives graded.

    Every input carries its tier and its basis. A reader can tell an observed number from a derived one, a derived one from a judgment, and a judgment from an honest unknown.

    Confirmed

    Observed in a primary document: a label section, a filing table, a registry record, a reported quarter.

    Derived

    Converted from a stated source — a comparable product, a fitted history — with the conversion written out.

    Judgment

    An analyst call, bounded and disclosed, with the reason it was made.

    Unknown

    Not found — and the record says where it was searched, so the next reader does not search twice.

    Every headline number is tagged four ways

    quantityAddressable patients scopeUS · second line tierConfirmed basisregistry series, multi-year

    Sell-side models are read for comparison, never copied as inputs. Where a number rests on weaker ground, that fact leads the deliverable.

    Controls

    Three controls before anything ships.

    Weak evidence is never hidden and never blocks a run. It is disclosed, ranked, and put first.

    01

    Machine check

    The run is refused if an assumption is silent, the arithmetic does not reconcile, a cited source cannot be opened, or the asset’s identity is unverified. Everything else passes — with its weakness on the record.

    refuses · exposes

    02

    Independent review

    A second reviewer with no access to the analyst’s reasoning re-opens every cited document and recomputes the chain. A disagreement is flagged on the first page, not absorbed into the number.

    re-opens · recomputes

    03

    Delivery

    The weakest assumptions lead the deliverable, each paired with the evidence that would replace it. Then the conclusion, with every number tagged.

    weakest first · then the call

    Foundation

    Built on a base that compounds.

    Three source families, five evidence agents working in parallel, and a library that grows with every run.

    Industry databases

    How the evidence is gathered

    Once the asset’s identity is locked, five evidence agents set out in parallel — clinical evidence, competitive pipeline, price and sales, development stage, epidemiology — and return facts with their sources. They never return a judgment. Positioning, share, price and the investment call stay with the investor.
